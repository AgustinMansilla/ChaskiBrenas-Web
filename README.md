# 📰 Chaski Breñas — Portal de noticias

Portal web informativo de Las Breñas, Chaco, con noticias locales y regionales, contenido editorial, publicidad y servicios para la comunidad.

**Desarrollado por Agustín Mansilla Emanuel**

## Funcionalidades

- **Portada:** noticias destacadas, carrusel y publicaciones recientes.
- **Noticias:** lectura de artículos, navegación por categorías y buscador.
- **Edición:** gestión de publicaciones, imágenes, categorías y contenidos destacados.
- **Publicidad:** anuncios y espacios promocionales dentro del portal.
- **Comunidad:** farmacias de turno, obituarios y servicios locales.
- **Información complementaria:** radio, clima y estadísticas de lectura.
- **Diseño adaptable:** experiencia en computadoras y dispositivos móviles.

## Tecnologías

| Área | Tecnologías |
| --- | --- |
| Interfaz original | React, TypeScript, Vite |
| Estilos | CSS, Tailwind CSS |
| Backend del sistema | PHP |
| Base de datos | MySQL |

## Interfaz y código

- [**Portal original**](demo/index.html): acceso a la web de noticias de Chaski Breñas con su diseño real.
- [**Frontend**](frontend/): componentes originales de la portada, navegación, noticias, publicidad y servicios comunitarios, con los estilos y configuración de React.
- [**Noticias y publicidad**](frontend/src/main.tsx): seis titulares publicados de la web y un anuncio de ejemplo para la carga de la interfaz.
- [**Publicidad de ejemplo**](frontend/public/publicidad-ejemplo.svg): recurso gráfico incluido en la presentación.
